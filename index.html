User Guidelines

This app times a gentle touch assay, records each animal's response, and exports the data ready for analysis.

How a session is organised

  • Assay — your configuration settings. Set this up once. Assays may contain one or more trials.
  • Trial — all animals in one session. Trials typically contain multiple runs (animals) that may belong to one or more genotypes.
  • Run — data from one animal. Time= ISI x Number of Stimulations. Each animal is a new run.

You can start as many trials as you like under one assay, and choose later whether to export them separately or pooled together. Pooling trials gets you aummary statistics across all trials(sessions/sittings).

Running the timer

  • Select a genotype, then press Start Timer.
  • You'll hear a cue for each interval. Administer the stimulus as soon as the cue starts.
  • You can choose between three different types of cues from the settings menu.
  • Tap only if the animal does not respond. If it responds, don't tap.
  • Tapping more than once in the same interval only counts as one tap.
  • When the last interval finishes, the run ends automatically. Press Start Timer again for the next animal. You can switch genotypes in between runs.

Stopping a run early

Press Stop Run if you need to end a run before it finishes (animal escapes, needs to be set aside, etc). The data already recorded is kept, but the run is marked as not eligible for the binned analysis, since it doesn't have a full set of intervals. It's still included in the raw data export.

Finishing a trial

Press Finish Trial once you're done with this sitting. You can start a new trial afterwards under the same assay, or move on to Export.

If the app is closed or refreshes unexpectedly during a trial, that trial is kept but marked as abandoned so you know it wasn't properly finished. Nothing is deleted.

Exporting

  • Choose which trials to include — a single trial, or a pooled export across several.
  • Pooled exports include completed trials by default. Include abandoned trials only if you choose to.
  • The export always contains the full raw data, plus a binned analysis (percentage response per bin, with mean and SEM tables) for eligible runs.
  • In addition, touch index is computed for each genotype, where the percentage response of all subsequent touch-bins is normalised to the percentage response in the first bin, allowing you to appreciate differences in how various genotypes adapt to repeated stimuli without the intial difference in sensation as a confounding factor.
  • If your total number of stimulations isn't an exact multiple of the bin size, only full bins are analysed — the rest stays in the raw data, with all exclusions reported in a separate sheet in the workbook.

Important

  • Deleting an assay permanently removes all its trials and runs.
  • Deleted assays cannot be recovered.
  • Export before deleting if you want to keep a record.
  • An assay will persist indefinitely till it is deleted.
